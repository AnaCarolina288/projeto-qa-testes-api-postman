# Projeto QA - Testes de API com Postman

Projeto desenvolvido para praticar testes de API utilizando o Postman.

Os testes foram realizados na API JSONPlaceholder, utilizando diferentes métodos HTTP e cenários positivos e negativos.

## O que foi testado

- Consulta de usuário existente
- Consulta de usuário inexistente
- Criação de novo usuário
- Atualização de usuário
- Exclusão de usuário
- Criação de usuário sem username
- Criação de usuário com e-mail inválido

## Tecnologias utilizadas

- Postman
- API REST
- JSON
- JavaScript para validações
- JSONPlaceholder

## Métodos HTTP utilizados

- GET
- POST
- PUT
- DELETE

## Validações realizadas

Durante os testes foram feitas validações de:

- Status codes (200, 201 e 404)
- Dados retornados no JSON
- ID do usuário
- Nome e e-mail
- Corpo da resposta
- Cenários com dados inválidos

## Objetivo do projeto

O objetivo deste projeto foi colocar em prática meus estudos de testes de API, criando requisições, validando respostas e criando testes no Postman.
